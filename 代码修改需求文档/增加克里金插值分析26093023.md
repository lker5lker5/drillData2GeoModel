## 一、需求概述

### 1.1 核心目标

在主建模流程（RBF 插值）之外，新增一个独立的"克里金数值分析"功能，用于**佐证和对比 RBF 建模的准确性**。

**核心产出**：
1. 克里金插值结果（2D 平面，与 RBF 同一层对比）
2. 预测方差热力图（克里金的独特价值，量化不确定性）
3. RBF vs 克里金对比图（并排展示）
4. 可用于报告的分析结论

### 1.2 关键决策

| 项 | 决策 |
|:---|:---|
| 分析对象 | 所有岩性层（每个岩性对顶面/底面分别分析） |
| 维度 | 2D 克里金（与 RBF 一致） |
| 变异函数 | 默认 `spherical`，前端可选 |
| 网格分辨率 | 与 RBF 一致（`GRID_RESOLUTION`） |
| 可视化 | 静态 PNG，2D 热力图 |
| 展示位置 | 右侧结果区，2x2 并排对比图（天然同步） |
| 控制点少 | 警告后继续 |
| 缓存 | 与建模图共用缓存机制 |
| 超时 | 耐心等待（有日志轮询） |

### 1.3 关于"两个区域同步"的技术说明

用户希望"分成两个区域，放大缩小与移动同步"。技术上有两种实现：

- **方案 A（推荐）**：用 matplotlib 生成一张并排图（2x2 布局），两个子图在同一画布内，天然同步。用户看到的就是一张图，整体缩放/平移。
- **方案 B**：用 Plotly 生成两个独立子图，通过 `relayout` 事件同步相机。实现复杂，且与"静态 PNG"冲突。

**采用方案 A**：简单、可靠、满足需求。
