# 地质体建模 Web 应用 — 项目说明文档 v2

> 基于钻孔数据的地质体三维建模与可视化 Web 应用，支持 RBF 和克里金两种插值方法，集成 AI 纹理生成、参数分析、模型质量评估等功能。

---

## 一、项目概述

### 1.1 项目定位
面向地质工程师的 Web 工具，上传钻孔勘探数据后自动构建三维地质体模型，并提供多视角可视化、插值方法对比、参数优化分析、AI 增强纹理、模型质量评估等能力。

### 1.2 技术栈

| 类别 | 技术 |
|------|------|
| 后端框架 | Flask 2.3.3 (Python 3) |
| 前端 | 原生 JavaScript (无框架) + Plotly.js (图表) |
| 3D 可视化 | Matplotlib (静态多视角) + Plotly (交互式 3D) |
| 插值引擎 | SciPy Rbf + PyKrige OrdinaryKriging |
| AI 集成 | 通义千问 (Qwen) 图像生成 API |
| 地图 | 天地图 API (坐标转换/底图) |
| 数据格式 | Excel (.xlsx) — 三表结构 |
| 测试框架 | pytest |
| 缓存 | 基于文件的内容哈希 + 参数哈希缓存 |

## 二、数据模型

### 2.1 钻孔 Excel 文件结构（三表）

项目使用单一 Excel 文件，需包含三个工作表（sheet）：

#### 定位表（`定位表`）
| 字段 | 说明 |
|------|------|
| 钻孔编号 | 唯一标识 |
| 开孔坐标N | 北坐标 (X) |
| 开孔坐标E | 东坐标 (Y) |
| 开孔高程R | 孔口高程 (Z) |

#### 测斜表（`测斜表`）
| 字段 | 说明 |
|------|------|
| 钻孔编号 | 关联定位表 |
| 侧斜深度 | 测量点深度 |
| 倾角 | 钻孔倾角 |
| 方位角 | 钻孔方位角 |

#### 岩性表（`岩性表`）
| 字段 | 说明 |
|------|------|
| 钻孔编号 | 关联定位表 |
| 上层位长度起始刻度 | 层顶深度 |
| 下层位长度起始刻度 | 层底深度 |
| 岩性描述 | 岩性名称 |
| 建模颜色 | HTML 颜色值 (#RRGGBB) |

### 2.2 Session（会话）
- 用户上传文件后自动创建 8 字符 UUID 标识的 session
- Session 存储路径：`uploads/{session_id}/`（上传文件）和 `outputs/{session_id}/`（生成结果）
- Session 生命周期：上传 → 操作 → 60 分钟无活动后过期清理
- 缓存存储：`outputs/_cache/{session_id}/`（基于内容哈希 + 参数哈希）

### 2.3 地质体模型数据结构

```
bodies = {
    "岩性名": {
        "X": ndarray (grid_res × grid_res),   # 网格 X 坐标（原始坐标）
        "Y": ndarray (grid_res × grid_res),   # 网格 Y 坐标（原始坐标）
        "Z_top": ndarray (grid_res × grid_res), # 顶面高程
        "Z_bot": ndarray (grid_res × grid_res), # 底面高程
        "color": "#RRGGBB"                      # 建模颜色
    },
    ...
}

volume_data = {
    "岩性名": {
        "X": ndarray,
        "Y": ndarray,
        "layers": [Z_layer0, Z_layer1, ...],  # 多层插值体切片
        "color": "#RRGGBB"
    },
    ...
}
```

## 四、核心模块说明

### 4.1 `mineDrillApp.py` — Flask 应用入口
- 路由分发（所有 `/api/*` 端点）
- Session 管理（创建、活跃跟踪、过期清理）
- 日志收集（`add_log` / `log_and_print`）
- 缓存清理守护线程

### 4.2 `processors.py` — 核心业务逻辑（~3500 行）
功能分区：

| 区间 | 功能 |
|------|------|
| `build_geological_bodies_with_volume_v2()` | 核心建模函数——读取三表、归一化、插值、凸包裁剪、体数据生成 |
| `generate_drill_views()` | 钻孔示意图（平面分布 + 剖面） |
| `generate_drill_model_only()` | 3D 模型多视角渲染（标注+无标注） |
| `generate_interactive_model()` | Plotly 交互式 3D 模型 |
| `optimize_rbf_params()` | RBF 参数网格搜索 + LOOCV 交叉验证 |
| `optimize_kriging_params()` | 克里金参数对比（多变异函数模型） |
| `fit_variogram_full_model()` | 变异函数参数提取（块金、基台、变程、R²） |
| `perform_kriging_analysis()` | 克里金曲面数值分析 |
| `generate_kriging_analysis_for_layer()` | 逐岩性克里金分析（顶面+底面） |
| `evaluate_rbf_loocv()` | RBF 留一法交叉验证评估 |
| `evaluate_kriging_loocv()` | 克里金留一法交叉验证评估 |
| `check_layer_intersection()` | 层间穿层检查 |
| `check_thickness_variation()` | 厚度变化梯度检查 |
| `detect_pinch_out()` | 尖灭识别 |
| `evaluate_model_quality()` | 综合质量评分与报告 |
| AI 相关 | `call_qwen_api_for_modeling()`、多视角生成、纹理升级、色彩统一 |

### 4.3 `config.py` — 集中配置
分组：
- 路径与文件：BASE_DIR、UPLOAD_FOLDER、OUTPUT_FOLDER
- 插值默认值：RBF_FUNCTION、RBF_SMOOTH、GRID_RESOLUTION、N_LAYERS
- 克里金配置：KRIGING_VARIOGRAM_MODEL、KRIGING_RMSE_STANDARDS、KRIGING_NUGGET_RATIO_STANDARDS、KRIGING_R2_STANDARDS
- RBF 配置：RBF_OPTIMIZE_FUNCTIONS、RBF_OPTIMIZE_SMOOTHS、RBF_RMSE_STANDARDS
- 质量评估配置：检查阈值、评分权重、评级标准
- AI 配置：QWEN_API_KEY、模型名称、评分权重
- 缓存配置：TTL、清理间隔、启用开关
- 用户可调参数白名单：`USER_ADJUSTABLE_PARAMS`

### 4.4 `params_manager.py` — 参数持久化
- `load_session_params(session_id)` — 加载 session 参数文件，与默认值合并返回
- `save_session_params(session_id, params)` — 保存参数（仅白名单键），校验范围
- `compute_params_hash(params)` — 对参数排序后计算 MD5 哈希，用于缓存键
- 参数文件存储：`uploads/{session_id}/user_params.json`

### 4.5 `cache_manager.py` — 缓存管理
- 基于内容哈希（文件 MD5）+ 参数哈希 + 缓存类型的三级缓存键
- 缓存存储：`outputs/_cache/{session_id}/{cache_type}/{input_hash}_{params_hash}.json`
- CRUD：`get_cached_result()` / `save_cached_result()` / `clear_cache_by_params_change()` / `clear_session_cache()`
- TTL：24 小时 + 后台清理线程

### 4.6 `analysis_manager.py` — 分析数据持久化
- 记录 RBF 和克里金的参数分析结果（包括控制点、插值预测、统计信息）
- 保存路径：`outputs/{session_id}/analysis_data.json`
- 分方法存储：rbf_analysis / kriging_analysis / kriging_surface_analysis

### 4.7 `scoring.py` — AI 图像评分
- SSIM（结构相似度）+ 色调直方图相似度
- 权重可配（默认 SSIM 0.6, 色调 0.4）
- 用于 AI 生成图的筛选排序

## 六、业务流程

### 6.1 标准工作流

```
上传 Excel → RBF/克里金参数分析 → 应用最佳参数 → 建模示意图 → AI 增强/交互模型
    │               │
    │               └→ 模型质量评估
    │
    └→ 钻孔示意图 → AI 概念建模 → 多视角生成 → 纹理升级
```

### 6.2 上传流程
1. 用户选择 Excel 文件（`post` → `/api/upload`）
2. 服务端解析三表，创建 session，返回会话 ID
3. 前端更新 `sessionId`、`filePath`，启用功能按钮
4. 自动加载模板数据预览

### 6.3 RBF 参数分析流程
1. 前端 POST `/api/analyze_rbf_params`（含 `target_layer` 选择）
2. 后端：
   a. 读取数据 → LOOCV 网格搜索（5 核函数 × 8 smooth 值 = 40 组合）
   b. 返回 `{best, all_results, success}`
3. 前端渲染推荐参数卡片 + RMSE 热力图
4. **自动**调用 `applyBestParams()` 保存到服务器，启用"建模示意图"

### 6.4 建模流程
1. 前端 POST `/api/generate_model`
2. 后端：
   a. 加载用户参数（RBF 核函数、平滑度、网格分辨率等）
   b. 调用 `build_geological_bodies_with_volume_v2()` 构建地质体
   c. 循环各视角，调用 Matplotlib 渲染（标注版 + 无标注版）
   d. 输出图片到 `outputs/{session_id}/`
3. 前端以轮播图展示各视角结果
4. 支持放大查看、下载单张、下载全部

### 6.5 质量评估流程
1. 前端 POST `/api/evaluate_quality`
2. 后端：
   a. 重建地质体 bodies（参数同当前 session）
   b. 执行 `check_layer_intersection()`、`check_thickness_variation()`、`detect_pinch_out()`
   c. `evaluate_model_quality()` 综合评分（满分 100，扣分制）
   d. 返回评分、评级、扣分项、局限、参数调整建议
3. 前端渲染 4 Tab 报告

## 七、插值方法详解

### 7.1 RBF（径向基函数插值）— 默认方法
- **库**: `scipy.interpolate.Rbf`
- **支持核函数**: multiquadric（默认）, thin_plate, linear, inverse_multiquadric, gaussian
- **关键参数**: `function`（核函数类型）+ `smooth`（平滑度，默认 0.1）
- **优点**: 精确插值（控制点处零误差），适合控制点密集的场景
- **缺点**: 外推可能震荡，控制点稀疏时质量下降

### 7.2 克里金法（Kriging）
- **库**: `pykrige.ok.OrdinaryKriging`
- **支持变异函数模型**: spherical（默认）, exponential, gaussian, linear, power
- **关键参数**: `variogram_model` + `nlags=6`
- **优点**: 提供方差估计、空间平滑性好
- **缺点**: 计算速度较慢

### 7.3 参数优化方法（LOOCV）
- 留一法交叉验证（Leave-One-Out Cross-Validation）
- 评价指标: RMSE（均方根误差）
- RBF 网格搜索: 5 核函数 × 8 smooth 值（0~1.0）
- 克里金对比: 5 变异函数模型逐一评估
- 分析结果推荐最佳参数并支持"应用此参数到当前会话"

### 7.4 克里金参数分析特有指标
- **块金值（Nugget）**: 空间变异中的随机部分
- **基台值（Sill）**: 总空间变异（块金 + 偏基台）
- **块基比（Nugget/Sill Ratio）**: <0.25 = 强空间相关, 0.25~0.75 = 中等, >0.75 = 弱
- **变程（Range）**: 空间自相关的最大距离
- **R²**: 变异函数模型拟合优度（>0.9 优秀, >0.7 良好, >0.5 一般）

---

## 八、模型质量评估模块

### 8.1 评估维度

| 维度 | 检测内容 | 扣分 |
|------|----------|------|
| 层间关系 | 顶面低于底面的穿层网格 | 30 分 |
| 厚度变化 | 厚度梯度 > 0.5 m/m 的异常网格 | 20 分 |
| 尖灭识别 | 非合理尖灭（硬切割） | 10 分 |

### 8.2 评级标准
- ≥90 分：优秀 🟢
- ≥75 分：良好 🔵
- ≥60 分：一般 🟠
- <60 分：差 🔴

### 8.3 输出建议
根据评估结果自动生成参数调整建议（如增大 RBF_SMOOTH、降低网格分辨率、切换克里金等），在综合报告 Tab 展示。

## 九、缓存机制

### 9.1 缓存键生成
```
cache_key = MD5(content_hash + "|" + params_hash + "|" + cache_type)
```
- `content_hash`: 输入 Excel 文件的 MD5
- `params_hash`: JSON 序列化后排序的用户参数 MD5
- `cache_type`: 各功能标识（model, rbf_analysis, kriging_analysis, quality_check 等）

### 9.2 缓存失效
- 用户修改参数后自动清除该 session 所有缓存
- 上传新文件产生新内容哈希，自然无法命中旧缓存
- 24 小时 TTL + 后台线程周期性清理过期缓存

## 十一、已知局限

1. **插值方法**: 仅支持 2D 插值（XY 平面 → Z），未考虑垂向各向异性
2. **断层处理**: 未建模断层，断层区域需人工加密钻孔
3. **地形约束**: 未引入地表 DEM 约束
4. **AI 生成**: 依赖外部 API，受 API 可用性和网络影响
5. **大规模数据**: 网格分辨率上限 100×100，钻孔数 > 100 时性能下降
6. **坐标系统**: 默认使用投影坐标（N/E），不支持经纬度直接输入
