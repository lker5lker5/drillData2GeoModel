# 地质勘查钻孔快速AI建模

用一组钻孔数据（定位表 / 测斜表 / 岩性表），在浏览器里一键生成三维钻孔示意图、地质体建模图、
可交互的三维模型，并可调用 AI 生成效果图、做插值参数分析与模型质量评估。

本文件是**使用说明书**：安装了哪些包、数据怎么准备、每个按钮做什么、参数怎么设、出了错怎么查。
术语含义另见 [`GLOSSARY.md`](GLOSSARY.md)。

---

## 1. 这个系统是什么 / 能做什么

**输入**：一个 Excel 文件，含三个工作表——定位表、测斜表、岩性表（格式见第 3 章）。

**输出**（都放在 `outputs/{会话号}/` 下，可在页面上查看和下载）：

| 功能 | 产出 |
|---|---|
| 🔬 钻孔示意图 | 6 个标准视角的 PNG，只画钻孔轨迹 |
| 🏔️ 建模示意图 | 6 视角 × 标注版/无标注版 = 12 张 PNG，地质体 + 钻孔 |
| 🌐 交互式3D模型 | 可在浏览器里旋转缩放的 HTML（钻孔页签 + 地质体页签两个页签） |
| 🤖 AI 建模 | 按你勾选的 3 张参考图，调用通义万相生成的效果图（候选图 + 自动评分） |
| 🎨 多视角纹理升级 | 6 个视角的 AI 纹理贴图成果图 |
| 📊 插值结果对比 | 克里金 vs RBF 的 2×2 对比图 + 数值报告 |
| 📊 克里金插值（2D） | 逐层顶面/底面的克里金曲面数值分析图 |
| 🔬 RBF / 📊 克里金 参数分析 | 最优插值参数推荐（核函数、平滑度、变异函数）+ 评分热力图 |
| ✅ 模型质量评估 | 层间穿层、厚度变化、尖灭的检查报告与评分（满分 100） |

**给你自己用**：整套东西跑在本机，端口 5001，数据（uploads/、outputs/）都留在本地目录里。

## 3. 输入数据格式

一个 Excel 文件，**三个工作表，表名必须完全一致**：`定位表`、`测斜表`、`岩性表`。
列名也必须一致（代码按列名读取，列的先后顺序无所谓）。
页面上「📥 下载模板」按钮可以直接下载标准模板（`钻孔数据模板.xlsx`）。

### 3.1 定位表（每个钻孔一行）

| 列名 | 含义 | 单位 | 必填 |
|---|---|---|---|
| `钻孔编号` | 孔号，三张表靠它对应 | — | 是 |
| `开孔坐标N` | 孔口北坐标 | m | 是 |
| `开孔坐标E` | 孔口东坐标 | m | 是 |
| `开孔高程R` | 孔口海拔 | m | 是 |
| `钻孔长度` | 孔深 | m | 否（只用于地图提示框） |
| `轨迹类型` | 直孔/斜孔标记 | — | 否（**当前版本不会被读取**） |

示例：`ZK901, 3182455.01, 523887.25, 286, 91.27, 曲`

### 3.2 测斜表（每个钻孔**多行**，一行一个测点）

| 列名 | 含义 | 单位 |
|---|---|---|
| `钻孔编号` | 孔号 | — |
| `各层位长度` | 沿孔深度（从孔口往下量的进尺） | m |
| `方位角` | 倾向方位，正北为 0°，顺时针 | ° |
| `倾角` | 倾角，**取绝对值**，正负号不影响结果 | ° |

示例：`ZK901, 0, 150.05, -44.97`

- 每个孔至少要 2 个测点才能连出轨迹；习惯上第一行给深度 0。
- 文件不必预先排序，程序会按 `各层位长度` 升序排列并去掉重复深度。

### 3.3 岩性表（每个钻孔**多行**，一行一个岩性段）

| 列名 | 含义 | 单位 |
|---|---|---|
| `钻孔编号` | 孔号 | — |
| `上层位长度起始刻度` | 该段起点深度 | m |
| `下层位长度起始刻度` | 该段终点深度 | m |
| `岩性描述` | 岩性名称，决定分层与图例 | — |
| `建模颜色` | 十六进制颜色，如 `#8B7355` | — |

示例：`ZK901, 0, 1.18, 第四系, #8B7355`

- 程序会按 `上层位长度起始刻度` 排序，不用预先排好。
- 颜色值不合法（或为空）的段会被忽略颜色设置。

### 3.4 三个坑（务必先自查）

1. **表名或列名写错，只会看到 pandas 的原始报错**，例如 `Worksheet named '岩性表' not found`
   或 `KeyError: '开孔坐标N'`。系统不做友好的格式校验，见到这类报错请先核对表名与列名。
2. **钻孔编号对不上就会被静默跳过**：岩性表里某个孔号在定位表里没有、或在测斜表里没测点，
   这个孔的岩性段不会出现在图里，也不会报错。
3. 三张表的孔号是**按字符串精确匹配**的，`ZK901` 与 `zk901`、`ZK 901` 会被当成不同孔。

## 5. 功能操作详解

左侧按钮分三组：`建模参数分析`、`可视化建模`、`插值分析`。右上角是文件操作，右下「运行信息」是日志。

### 5.1 建模参数分析组

**`🔬 RBF 参数分析`**
弹出「选择要分析的岩性层」（可选整体或单个岩性），后台按 `RBF核函数 × 平滑度 × epsilon` 的组合
试算，输出：`✨ 推荐参数`（核函数/平滑度/epsilon/RMSE/MAE/最大误差/综合评分/建议）、
`📊 综合评分热力图`、`📋 参数组合明细`（按评分降序前 30 项），并有 `📋 复制参数`。
**分析成功后会自动应用最优参数**，同时解锁 `🏔️ 建模示意图`。
控制点少于 5 个时返回「控制点数量不足（N < 5），无法可靠评估」。

**`📊 克里金参数分析`**
同样的选层流程，逐个变异函数试算，给出推荐变异函数与评分。注意：**它不会解锁建模示意图**。

**`✅ 模型质量评估`**（满分 100 分）
四张检查表：`层间关系检查`（穿层）、`厚度变化检查`（厚度梯度与极值）、`尖灭识别`、`综合质量报告`。
判定标准：
- 穿层：单点穿层厚度 > 0.5 m 判定为穿层；比例 > 1% 告警、> 5% 判不合格
- 厚度：梯度 > 0.5 m/m 告警；厚度 < 0.5 m 或 > 200 m 告警
- 尖灭：厚度 < 1.0 m 记为尖灭；尖灭比例 > 20% 视为合理
- 扣分：穿层 −30、厚度 −20、尖灭 −10；等级 ≥90 优、≥75 良、≥60 中

**`⚙️ 建模参数`**
页内参数编辑器，分「建模参数」「钻孔显示参数」「插值参数」三组，改完点 `应用参数`。
提示语是「参数已应用，**下次生成时生效**」。参数含义与取值范围见第 6 章。
改动参数会清掉该会话已有的建模/插值/评估缓存。

### 5.2 可视化建模组

**`🔬 钻孔示意图`** — 6 张 PNG，只画钻孔轨迹（不带地质体），每个标准视角一张。
用来先单独检查钻孔的空间分布与形态。

**`🏔️ 建模示意图`** — 12 张 PNG：6 个标准视角 × 标注版/无标注版。
- 标注版：完整坐标轴 + 钻孔编号 + 图例
- 无标注版：隐藏 X/Y 轴，只留高程轴，可直接当成果图
左右两个轮播联动，点一张看得更清楚。下方同时出现 `🤖 AI 建模参考图选择` 区。

**`🌐 交互式3D模型`** — 在弹窗里打开，两个页签：
- `🔬 钻孔3D模型`：只含钻孔轨迹，与钻孔示意图对应
- `🏔️ 地质体模型`：地质体 + 钻孔，点开时才生成（内容较大）

地质体页签左下有三个控制面板：
- `📐 分层观察`：0–100% 滑块，把各岩性层水平拉开看内部结构，`重置` 可归位
- `岩性显隐`：逐个岩性勾选显示/隐藏
- `🔬 钻孔`：开关，控制钻孔轨迹的显示
- `📐 体积估算`：见下

**体积估算面板**：拖动 `X (东) 范围`、`Y (北) 范围`、`Z (高程) 范围` 三组双滑块框定范围，
面板实时给出总体积、`有效网格` 占比与网格面积；多岩性时还给出分岩性明细。
体积单位自动换算：小于 100 万 m³ 用 `m³`，100 万以上用 `百万 m³`，10 亿以上用 `km³`。
另有 `🔄 框体绕Z轴/X轴/Y轴旋转` 三个滑块（−90°~90°），以框体中心为轴旋转，打开/关闭面板时归零。
只有一种岩性时不分岩性勾选。操作手感：**拖动滑块时只刷新数值，松开鼠标才更新三维框体**，
这样拖动不会卡顿。

**`🤖 AI 建模`** — 前提：已出过建模示意图（需要配色方案），且**恰好勾选 3 张参考图**。
调用通义万相（模型 `qwen-image-3.0-pro`）生成候选图，自动打分并列出每张的
`🔍`（放大）、`⬇`（下载）、`使用这张`（选定）。两张候选评分接近时会提示人工对比选择。
客户端超时 300 秒，超时会中断。

**`🎨 多视角纹理升级`** — 前提：已出过建模示意图。对 6 个固定视角逐张做 AI 纹理贴图与色彩统一，
输出轮播带 `📥 下载当前图` 与 `📥 下载全部`（打包成 zip）。

### 5.3 插值分析组

**`📊 插值结果对比`** — 逐岩性输出 2×2 对比图：左上克里金、右上 RBF、左下预测标准差、右下差值；
另有 `📋 数值分析报告` 页签和 `⬇ 导出报告`（导出 `.txt`，文件名 `克里金分析报告_日期.txt`）。
每层顶/底控制点少于 5 个会被跳过（提示「控制点过少（顶N个/底N个，需要≥5个）」）。

**`📊 克里金插值（2D）`** — 逐层给出顶面、底面的克里金曲面数值分析图，
下方 `⚠️ 注意事项` 会列出控制点少于 10 个的层（"分析结果可靠性较低"）。

### 5.4 结果区与文件操作

- 右侧页签 `📊 可视化结果` / `📈 数据说明`。数据说明页里有：各层统计汇总表
  （方法/岩性/层位/控制点数/最小值/最大值/均值/标准差/平均方差）、散点与直方图、
  以及 `📥 导出分析数据（ZIP）`（导出 CSV + Excel，按岩性分文件夹）。
- `运行信息` 面板每 800 ms 刷新一次后台日志，按级别着色。
- 各按钮上有计时器（`已用时 MM分SS秒`）；注意**参数分析与质量评估的进度条是估算的**
  （后台是同步计算，拿不到真实进度），最长会停在 90% 等结果返回。
- 右上角：`🔄 新建会话`（清空当前会话重新开始）、`🗑️ 清除历史记录`（清空所有历史输出，不可撤销）。

### 5.5 文件存在哪

每次上传生成一个 8 位会话号，所有产物按会话存放：

```
outputs/{会话号}/          图片、HTML、日志
outputs/{会话号}/_cache/   缓存元数据与参数分析数据
uploads/{会话号}/          你上传的 Excel、该会话的 user_params.json
```

**要留的成果必须下载下来**：会话 60 分钟无操作后自动清理，上传新文件会立刻删掉旧会话。

## 6. 参数设置总表

### 6.1 用户可调参数（`⚙️ 建模参数` 里能改的 8 个）

| 参数 | 含义 | 默认值 | 取值范围 | 影响 |
|---|---|---|---|---|
| 网格分辨率 `GRID_RESOLUTION` | 插值网格每条边的格数 | 50 | 10–100 | 越密模型越精细，计算越慢 |
| 体渲染层数 `N_LAYERS` | 体渲染切层数 | 自动 | 5–50（可勾「自动」） | 自动模式按岩性厚度算：`max(5, min(25, int(6 + 平均厚度/30)))`；层数越多叠层观感越细 |
| 钻孔样式 `DRILL_STYLE` | 钻孔画成什么 | 圆柱体 | 圆柱体 / 线段 | 圆柱体好看但更重 |
| 钻孔半径（米）`DRILL_RADIUS` | 圆柱半径 | 3.0 | 0.5–20 | 建议 1~5 米 |
| RBF核函数 `RBF_FUNCTION` | RBF 插值核 | multiquadric | multiquadric / thin_plate / linear / inverse_multiquadric / gaussian | 直接影响建模曲面形态，可让 RBF 参数分析帮你选 |
| RBF平滑度 `RBF_SMOOTH` | RBF 平滑系数 | 0.1 | 0–10 | 越大越平滑；设为极小值接近精确插值 |
| 插值方法 `INTERPOLATION_METHOD` | 用哪种插值 | rbf | rbf / kriging | 克里金需要装 `pykrige`；**克里金失败会自动回退到 RBF，且只打日志不报错** |
| 克里金变异函数 `KRIGING_VARIOGRAM` | 克里金变异模型 | spherical | spherical / exponential / gaussian / linear / power | 只在插值方法选克里金时起作用 |

参数存在**两个地方**：服务端 `uploads/{会话号}/user_params.json`，以及浏览器 `localStorage`。
页面打开时以服务端为准、用 localStorage 覆盖显示；点「应用参数」会写回服务端。

### 6.2 需要改配置文件才能调的参数（`config.py`）

| 参数 | 默认值 | 说明 |
|---|---|---|
| `PORT` / `HOST` | 5001 / `0.0.0.0` | 服务端口与监听地址 |
| `DEBUG` | `True` | 正式使用建议改 `False` |
| `MAX_FILE_SIZE` | 50 MB | 上传上限 |
| `SESSION_TIMEOUT_MINUTES` | 60 | 会话无操作过期时间（后台每 3600 秒扫一次） |
| `CACHE_TTL_HOURS` | 24 | 结果缓存有效期 |
| `FIGURE_DPI` / `FIGURE_WIDTH` / `FIGURE_HEIGHT` | 300 / 14 / 11 | 输出图片清晰度与尺寸 |
| `VIEW_CONFIGS` | 6 个视角 | 定位：主视图 25°/−45°、东西向侧视 0°/0°、南北向侧视 0°/90°、俯视 90°/−90°、补充立体 25°/135°、等轴测 35.264°/−45° |
| `DRILL_CYLINDER_SIDES` | 8 | 圆柱面片数 |
| `DRILL_DEGRADE_THRESHOLD` / `DRILL_FORCE_LINE_THRESHOLD` | 2000 / 5000 | 岩性段总数超过阈值时**自动降级为线段**（超过 5000 强制极简线段）。这两条提示只打在终端，不在页面日志里 |
| `KRIGING_MIN_POINTS_WARN` | 10 | 控制点数低于此值给出可靠性告警 |
| `QWEN_MODEL` / `QWEN_API_URL` | `qwen-image-3.0-pro` / 阿里云 MaaS 接口 | AI 建模用的模型与地址 |
| `AI_DEFAULT_REFERENCE_VIEWS` | 主视图 / 东西向侧视 / 南北向侧视 | AI 建模默认预选的 3 张参考图 |
| `MULTIVIEW_VIEW_ORDERS` | 1–6 | 多视角纹理升级处理的视角 |
| `MULTIVIEW_COLOR_METHOD` / `MULTIVIEW_UNIFY_COLOR` | reinhard / True | 多视角之间的色彩统一方式 |
| `SCORE_WEIGHT_SSIM` / `SCORE_WEIGHT_COLOR` | 0.6 / 0.4 | AI 效果图自动评分的权重 |
| `SCORE_DIFF_THRESHOLD` | 0.05 | 两张候选评分差值小于它时提示人工对比 |
| `QUALITY_*` | 见 5.1 | 质量评估的阈值、扣分与等级线 |
| `ENABLE_QUALITY_CHECK` | `True` | 关掉后质量评估按钮会提示「功能未启用」 |

### 6.3 结果可复现性

建模、克里金、RBF 的计算都是确定性的（代码里没有随机种子）。**唯一不可复现的是 AI 效果图**，
由外部服务生成，每次都不一样。

## 7. 坐标与单位约定

### 7.1 三维视图的轴

所有出图（钻孔示意图、建模示意图、交互式3D模型，以及 `📊 插值结果对比` 的 2×2 平面图）一律：

| 轴 | 画的是 | 轴标题 |
|---|---|---|
| X 轴 | 定位表的 `开孔坐标E`（东坐标） | 东 (m) / 开孔坐标E (m) |
| Y 轴 | 定位表的 `开孔坐标N`（北坐标） | 北 (m) / 开孔坐标N (m) |
| Z 轴 | 高程（海拔） | 海拔 (m) / 海拔高度 (m) |

- 朝向按地图惯例（**上北、右东**）：X 轴朝东、Y 轴朝北、Z 轴朝上。俯视平面图就是一张正放的平面图——
  北在屏幕上方、东在屏幕右侧；钻孔的偏斜方向也与测斜表对得上（方位角 0° 沿 Y 轴偏、90° 沿 X 轴偏）。
- **一律使用绝对坐标**（钻孔表里的原始值），不做任何原点平移。因此轴上的读数可以**直接与钻孔表逐值对照**。
- **坐标轴刻度只显示整数**（不显示小数位），把鼠标移到图上时显示的数值保留两位小数。
- 界面顶部也标明了这条约定：「坐标约定：X=东，Y=北，Z=高程（向上）」（`templates/index.html:33`）。
- 首页默认显示的演示页「钻孔角度关系演示」（`static/drillAngleExplain.HTML`）与上表同一套朝向：
  X 轴=东、Y 轴=北、Z 轴=上；方位角以正北为 0°、顺时针，与测斜表的 `方位角` 含义一致。

### 7.2 单位与角度

| 量 | 单位 | 说明 |
|---|---|---|
| 坐标 N / E / 高程 R | 米 | 与测量控制网一致 |
| 钻孔长度、各层位长度 | 米 | 沿孔深度（进尺），不是垂深 |
| 方位角 | 度 | 正北 0°，顺时针增加 |
| 倾角 | 度 | **取绝对值**，写成负值不影响结果 |
| 厚度 / 梯度 | 米 / 米每米 | 用于质量评估判定 |
| 体积 | m³ | 界面自动换算为 百万 m³ / km³ |

孔内某点的高程由「开孔高程 R + 轨迹积分」推算，**向下为负**。

### 7.3 2026-10 版与旧版产物的差异

7.1 那套朝向（X=东、Y=北、Z=上）是 2026-10 才统一的。之前出图把北坐标放在 X 轴、东坐标放在 Y 轴，
而且**钻孔的偏斜量加到了相反的轴上**（方位角 0° 的正北孔被画成沿东轴走）。旧版产物因此：

- 每张三维图都是**真实场地的镜像**——俯视平面图上北朝上时，东落在屏幕**左**侧；
- 矿体控制点的平面位置跟着错，所以**形状与体积都不对**。

新版两处一起修正。带来的影响：

| 会变的 | 说明 |
|---|---|
| 体积、平面投影面积 | 同一批数据差几个百分点（合成数据实测：一个岩性 −9.7%、另一个 −6.6%），分岩性明细同理 |
| 钻孔朝向、矿体形状 | 摆正到与测斜表一致（方位角 0° 沿 Y 轴偏、90° 沿 X 轴偏） |
| AI 图 | `🤖 AI 建模`、`🎨 多视角纹理升级` 的产物需重跑，旧图不可复用 |
| 体积面板旋转手感 | 「框体绕 Z 轴旋转」的正负观感与旧版相反（公式没变，是坐标系手性变了） |

**不受影响**：参数推荐值（RMSE / MAE / 综合评分等）、输入的三个表格式、界面布局。

**旧版报告里的体积数字不能与新版直接对照**，请以新版重跑的结果为准。

## 8. 已知局限与注意事项

**使用前必须知道的三条**

1. **结果是临时的**：会话 60 分钟无操作就清理；上传新文件立即删除上一个会话。**要留的图请先下载。**
2. **钻孔示意图与建模示意图的轮播上没有下载按钮**（只有 🔍 放大）。要保存这两类图，
   可在放大视图上右键另存。带下载按钮的是「多视角纹理升级」的轮播与「数据说明」页的导出。
3. **`🏔️ 建模示意图` 必须先跑过一次 `🔬 RBF 参数分析` 才能点**，只跑克里金参数分析不会解锁。

**数据与结果相关的坑**

4. 输入没有任何格式校验：表名/列名写错就是 pandas 的原始报错；孔号对不上或在测斜表缺测点的岩性段会被静默丢弃。
5. 克里金报错会**静默回退到 RBF**，日志里有「克里金插值失败…回退到 RBF」，但页面结果不会提示你用的其实是 RBF。
6. 每层顶/底控制点少于 5 个会被跳过；少于 10 个只给"可靠性较低"的告警。
7. 岩性段总数超过 2000 时钻孔自动降级为线段、超过 5000 强制极简线段；**这两条提示只出现在终端，不在页面日志**。
8. 参数分析与质量评估是同步阻塞计算，页面上的进度条是估算的（最高停 90%），大文件会等较久。
9. AI 建模客户端 300 秒超时；AI 接口不可用时只能重试。
10. 旧文档 `项目需求文档/项目说明文档v2.md` 已过时（入口写成 `main.py`、列了不存在的接口、
    测斜表列名写错、依赖漏项），**以本文件为准**。

## 9. 常见问题

**Q：启动就报缺某个包？**
`pip install -r requirements.txt`。

**Q：点克里金相关功能报「缺少依赖包，请执行 pip install pykrige」？**
`pip install pykrige`。或者把 `插值方法` 改成 RBF。

**Q：`🤖 AI 建模` 提示「API密钥未配置」？**
启动前 `export QWEN_KEY=你的密钥`。

**Q：`🏔️ 建模示意图` 按钮是灰的？**
先成功跑一次 `🔬 RBF 参数分析`。

**Q：上传后报 `Worksheet named '岩性表' not found`？**
工作表名必须是 `定位表`、`测斜表`、`岩性表` 三个，不能改名、不能多空格。

**Q：图上钻孔数量比表里少？**
该孔号在定位表里缺失，或在测斜表里测点少于 2 个，会被跳过。核对孔号是否一致（大小写、空格）。

**Q：坐标轴数值和钻孔表对不上？**
X 轴读的是定位表 `开孔坐标E`（东）、Y 轴读 `开孔坐标N`（北），且一律显示绝对坐标、不做原点平移，
所以轴读数应与定位表逐值对应（只差刻度的取整，鼠标悬停看两位小数）。
若对不上，先确认看的是不是旧版本产物（旧版把东/北两列放在了相反的轴上，见 7.3 节）或钻机局部坐标。

**Q：昨天生成的图找不到了？**
会话过期（60 分钟）或被新上传清理了。生成后请立即下载。

**Q：点位展示地图打不开？**
需要 `ZJ_TIANDITU_KEY`。

**Q：模型质量评估说按钮未启用？**
`config.py` 里 `ENABLE_QUALITY_CHECK` 被改成了 `False`。

### 10.3 缓存与清理机制

- 结果按「参数哈希」缓存：`outputs/{会话号}/_cache/`；改参数即失效，缓存有效期 24 小时。
- 会话 60 分钟无请求即过期，后台每 1 小时扫一次，删除该会话的 `outputs/`、`uploads/`、日志。
- 程序启动时清空上次残留的 `uploads/` 与历史 `outputs/`。
