## 一、需求概述

### 1.1 核心目标

在上传数据后，新增一个"RBF 参数分析"按钮，用于：
1. 遍历 RBF 核函数和 smooth 参数的所有组合
2. 用留一交叉验证（LOOCV）计算每组参数的 RMSE
3. 输出建议选择的核函数、平滑度和预期误差
4. 推荐一组较为合理的参数作为参考
5. 展示 RMSE 参考标准，并高亮当前结果所处区间

### 1.2 关键决策

| 项 | 决策 |
|:---|:---|
| 分析粒度 | 让用户选（整体 or 某岩性层），默认整体 |
| 参数范围 | 含 gaussian，更多 smooth 值（见 1.3） |
| 按钮位置 | 左侧面板"预览数据"按钮之后 |
| 展示位置 | 右侧结果区 |
| 展示形式 | 参数表格 + RMSE 热力图 + 推荐卡片 + 参考标准表 |
| 一键应用 | 提供按钮，参数只保存在前端当前会话（currentParams） |
| 进度反馈 | 日志轮询 + 按钮下方进度条 |
| 缓存 | 需要（task_type='rbf_analysis'） |
| 与克里金关系 | 完全独立 |

### 1.3 参数搜索范围

**核函数列表**：`['multiquadric', 'thin_plate', 'linear', 'inverse_multiquadric', 'gaussian']`

**smooth 列表**：`[0, 0.0001, 0.001, 0.01, 0.05, 0.1, 0.5, 1.0]`

**epsilon 列表**（仅 gaussian 需要）：`[0.1, 0.5, 1.0, 2.0]`

**组合总数**：
- 4 个不需 epsilon 的核函数 × 8 个 smooth = 32 个组合
- gaussian × 8 个 smooth × 4 个 epsilon = 32 个组合
- **总计：64 个组合**

### 1.4 RMSE 参考标准

| RMSE 范围 | 评价 | 建议 |
|:---|:---|:---|
| < 5 m | 优秀 | 直接采用 |
| 5 ~ 15 m | 良好 | 可用于宏观展示 |
| 15 ~ 30 m | 一般 | 需检查数据质量 |
| > 30 m | 差 | 数据可能有问题，或控制点分布太稀疏 |

### 3.2 新增函数 `evaluate_rbf_loocv`

```python
def evaluate_rbf_loocv(x, y, z, rbf_function='multiquadric', smooth=0.01, epsilon=None):
    """
    用留一交叉验证（LOOCV）评估 RBF 模型的泛化误差。
    """
    import numpy as np
    from scipy.interpolate import Rbf
    
    n = len(x)
    if n < 5:
        return {
            'rmse': None, 'mae': None, 'max_error': None,
            'n_points': n, 'success': False,
            'error': f'控制点数量不足（{n} < 5），无法可靠评估'
        }
    
    # 归一化
    x_min, x_max = x.min(), x.max()
    y_min, y_max = y.min(), y.max()
    z_min, z_max = z.min(), z.max()
    
    x_span = x_max - x_min if x_max > x_min else 1.0
    y_span = y_max - y_min if y_max > y_min else 1.0
    z_span = z_max - z_min if z_max > z_min else 1.0
    
    x_n = (x - x_min) / x_span
    y_n = (y - y_min) / y_span
    z_n = (z - z_min) / z_span
    
    errors = []
    needs_epsilon = rbf_function in ['gaussian', 'multiquadric', 
                                      'inverse_multiquadric', 'inverse']
    
    for i in range(n):
        mask = np.ones(n, dtype=bool)
        mask[i] = False
        
        x_train = x_n[mask]
        y_train = y_n[mask]
        z_train = z_n[mask]
        
        try:
            kwargs = {'function': rbf_function, 'smooth': smooth}
            if epsilon is not None and needs_epsilon:
                kwargs['epsilon'] = epsilon
            
            rbf = Rbf(x_train, y_train, z_train, **kwargs)
            z_pred = rbf(x_n[i], y_n[i])
            err = (z_pred - z_n[i]) * z_span
            errors.append(err)
        except Exception:
            continue
    
    if len(errors) == 0:
        return {
            'rmse': None, 'mae': None, 'max_error': None,
            'n_points': n, 'success': False,
            'error': '所有点拟合均失败'
        }
    
    errors = np.array(errors)
    return {
        'rmse': float(np.sqrt(np.mean(errors ** 2))),
        'mae': float(np.mean(np.abs(errors))),
        'max_error': float(np.max(np.abs(errors))),
        'n_points': n,
        'success': True,
        'error': None
    }
```

### 3.3 新增函数 `optimize_rbf_params`

```python
def optimize_rbf_params(
    x, y, z,
    functions=None,
    smooths=None,
    epsilons=None,
    progress_callback=None
):
    """
    网格搜索 + LOOCV，寻找最优的 RBF 参数组合。
    
    progress_callback: 可选，进度回调函数，签名为 callback(current, total, info)
    """
    import numpy as np
    from config import (
        RBF_OPTIMIZE_FUNCTIONS, RBF_OPTIMIZE_SMOOTHS, RBF_OPTIMIZE_EPSILONS
    )
    
    if functions is None:
        functions = RBF_OPTIMIZE_FUNCTIONS
    if smooths is None:
        smooths = RBF_OPTIMIZE_SMOOTHS
    if epsilons is None:
        epsilons = RBF_OPTIMIZE_EPSILONS
    
    needs_epsilon = {'gaussian', 'multiquadric', 'inverse_multiquadric', 'inverse'}
    
    # 构建组合列表
    combos = []
    for func in functions:
        for sm in smooths:
            if func in needs_epsilon:
                # 需要 epsilon 的核函数，遍历所有 epsilon
                for eps in epsilons:
                    combos.append((func, sm, eps))
            else:
                # 不需要 epsilon
                combos.append((func, sm, None))
    
    total = len(combos)
    all_results = []
    best = None
    
    print(f"==> 开始 RBF 参数寻优，共 {total} 个组合，每个组合执行 {len(x)} 次留一验证")
    
    for idx, (func, sm, eps) in enumerate(combos, 1):
        result = evaluate_rbf_loocv(x, y, z, func, sm, eps)
        
        if not result['success']:
            if progress_callback:
                progress_callback(idx, total, f'{func}/smooth={sm} 失败: {result["error"]}')
            continue
        
        entry = {
            'rbf_function': func,
            'smooth': sm,
            'epsilon': eps,
            'rmse': result['rmse'],
            'mae': result['mae'],
            'max_error': result['max_error']
        }
        all_results.append(entry)
        
        if best is None or result['rmse'] < best['rmse']:
            best = entry.copy()
            print(f"  [{idx}/{total}] 新最优: {func} smooth={sm} "
                  f"eps={eps} RMSE={result['rmse']:.4f}m")
        
        if progress_callback:
            progress_callback(idx, total, f'{func}/smooth={sm} RMSE={result["rmse"]:.4f}')
    
    if best is None:
        return {
            'best': None, 'all_results': [],
            'success': False,
            'error': '所有参数组合均失败'
        }
    
    print(f"==> 最优参数: {best['rbf_function']} smooth={best['smooth']} "
          f"epsilon={best['epsilon']} RMSE={best['rmse']:.4f}m")
    
    return {
        'best': best,
        'all_results': all_results,
        'success': True,
        'error': None
    }
```

### 6.3 新增渲染函数 `renderRBFAnalysisResults`

```javascript
function renderRBFAnalysisResults(data) {
    const resultsSection = document.getElementById('resultsSection');
    resultsSection.innerHTML = '';
    resultsSection.classList.add('visible');
    
    const analysisKeys = Object.keys(data.analysis);
    if (analysisKeys.length === 0) {
        resultsSection.innerHTML = '<p>无分析结果</p>';
        return;
    }
    
    const key = analysisKeys[0];
    const result = data.analysis[key];
    
    if (!result.success) {
        resultsSection.innerHTML = `<p style="color:#c62828;">分析失败: ${result.error}</p>`;
        return;
    }
    
    const best = result.best;
    const allResults = result.all_results;
    const standards = data.standards;
    
    // 判断最优 RMSE 属于哪个标准
    let currentStd = standards[standards.length - 1];
    for (const std of standards) {
        if (best.rmse < std.max) {
            currentStd = std;
            break;
        }
    }
```

### 6.4 新增热力图函数 `drawRMSEHeatmap`

```javascript
function drawRMSEHeatmap(allResults) {
    const functions = [...new Set(allResults.map(r => r.rbf_function))];
    const smooths = [...new Set(allResults.map(r => r.smooth))].sort((a, b) => a - b);
    
    // 构建 RMSE 矩阵
    const rmseMatrix = [];
    for (const func of functions) {
        const row = [];
        for (const sm of smooths) {
            const candidates = allResults.filter(r => r.rbf_function === func && r.smooth === sm);
            if (candidates.length > 0) {
                const minRmse = Math.min(...candidates.map(c => c.rmse));
                row.push(minRmse);
            } else {
                row.push(null);
            }
        }
        rmseMatrix.push(row);
    }
    
    const trace = {
        z: rmseMatrix,
        x: smooths.map(String),
        y: functions,
        type: 'heatmap',
        colorscale: 'RdYlGn_r',
        showscale: true,
        colorbar: { title: 'RMSE (m)' },
        hovertemplate: '核函数: %{y}<br>smooth: %{x}<br>RMSE: %{z:.2f}m<extra></extra>'
    };
    
    const layout = {
        xaxis: { title: '平滑度 (smooth)' },
        yaxis: { title: '核函数' },
        margin: { l: 120, r: 40, t: 20, b: 60 }
    };
    
    Plotly.newPlot('rmseHeatmap', [trace], layout, { responsive: true });
}
```

```javascript
function applyBestParams(best) {
    if (!best) return;
    
    // 只保存到前端当前会话的 currentParams
    if (typeof currentParams !== 'object') {
        currentParams = {};
    }
    
    currentParams.RBF_FUNCTION = best.rbf_function;
    currentParams.RBF_SMOOTH = best.smooth;
    
    // 如果参数面板已渲染，更新输入框
    const funcEl = document.getElementById('param_RBF_FUNCTION');
    if (funcEl) funcEl.value = best.rbf_function;
    
    const smoothEl = document.getElementById('param_RBF_SMOOTH_input');
    if (smoothEl) smoothEl.value = best.smooth;
    
    const smoothSlider = document.getElementById('param_RBF_SMOOTH_slider');
    if (smoothSlider) smoothSlider.value = best.smooth;
    
    // 提示
    setStatus('==> 推荐参数已应用到当前会话（下次生成时生效）', 'success');
    
    setTimeout(() => {
        const hint = document.getElementById('paramsHint');
        if (hint) {
            hint.textContent = '已从参数分析结果应用 RBF 参数';
            hint.style.color = '#2E7D32';
        }
    }, 300);
}

function copyBestParams(best) {
```

## 十、注意事项

1. **计算时间**：64 个组合 × N 个控制点 × 单次拟合耗时。N=50 时约 1~2 分钟，N=200 时约 5~8 分钟。建议加日志和进度条。

2. **进度条的"假进度"**：由于后端是同步阻塞的，前端只能用定时器模拟进度。真实进度需要后端用 SSE 或 WebSocket 推送，本次不实现。

3. **epsilon 参数**：只有 gaussian 需要，其他核函数即使传了也会被 Rbf 忽略。所以热力图对每个 (func, smooth) 组合取"最优 epsilon 的 RMSE"。

4. **一键应用只保存到前端**：因为用户要求"只保存在前端当前会话中"，所以 `currentParams` 会更新，但不会调用 `/api/save_params`。下次点击"生成建模图"时，前端会把这个值随请求带上（如果现有流程支持）。

5. **缓存键**：因为参数分析涉及不同 target_layer，缓存键需要加上 `target_layer` 后缀，否则会误命中。

6. **参考标准的高亮**：只高亮"最优 RMSE 所处区间"，其他区间正常显示。

7. **控制点数少的层**：如果某岩性层控制点 < 5，该层分析会失败（LOOCV 至少需要 5 个点）。建议在前端选择列表里过滤掉这类层。
