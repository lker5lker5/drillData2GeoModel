## TC-01 上传与格式校验

### 1.1 有效数据（A 跑全，B 抽查）

| # | 操作 | 期望 | 判定 |
|---|---|---|---|
| 1 | 上传数据 A | 无报错，返回 8 位 session id | Network `/api/upload` 响应 |
| 2 | 预览"定位表" | 行数 = Excel 实际钻孔数；N/E/R 逐行一致（无小数点位移、正负号丢失） | 抽样 3 行对照 Excel |
| 3 | 预览"测斜表" | 行数、深度、倾角、方位角一致 | 抽样 3 行 |

| 6 | 按钮状态 | 上传后功能按钮变为可用 | 灰色 = 失败 |

### 1.2 坏数据（5 个各跑一遍）

| 文件 | 期望 |
|---|---|

## TC-02 参数分析链路（数据 A）

依次点击，**不刷新页面**。

### 2.1 RBF 参数分析（target = 整体）

| 检查项 | 期望 |
|---|---|
| 返回结果 | 推荐参数卡片 + RMSE 热力图 |
| 推荐核函数 | ∈ {multiquadric, thin_plate, linear, inverse_multiquadric, gaussian} |
| 推荐 smooth | 0~1.0，且有对应 RMSE |
| 热力图 | 5×8 = 40 格全有值，无空白/NaN |
| 结果自洽 | 卡片"最优 RMSE" = 热力图最小值 |

### 2.2 克里金参数分析（target = 整体）

| 检查项 | 期望 |
|---|---|
| 返回结果 | 推荐卡片 + 模型详情表 + 3 张图（RMSE / 块基比 / R²） |
| 推荐模型 | ∈ {spherical, exponential, gaussian, linear, power} |
| 块基比 | 推荐模型的块基比与图中该模型的值一致 |
| R² | 推荐模型的 R² 与图中一致 |

### 2.3 模型质量评估

| 检查项 | 期望 |
|---|---|
| 返回 4 个 Tab | 层间关系 / 厚度变化 / 尖灭识别 / 综合质量 |
| 评分 | 0~100，评级与分数对应（≥90优秀 / ≥75良好 / ≥60一般 / <60差） |
| 扣分项 | 三项扣分（30/20/10）之和 = 100 - 得分 |
| 参数建议 | 非满分时必须有具体建议，不能空数组 |

### 2.4 建模参数页 ↔ 推荐参数 一致性（**重点**）

点开"建模参数"，对照 2.1、2.2：

| 建模参数页字段 | 应等于 |
|---|---|
| RBF 核函数 | 2.1 推荐核函数 |
| RBF smooth | 2.1 推荐 smooth |
| 克里金变异函数模型 | 2.2 推荐模型 |

任一不一致 → 记入 `test_log.md`，注明"推荐值 X，页面显示 Y"。

## TC-04 缓存命中验证

**前提**：TC-02、TC-03 已跑完，参数未改动，session 未变。

对以下按钮逐个重复点击（第二次点击前后不修改任何参数）：
`RBF参数分析` / `克里金参数分析` / `模型质量评估` / `钻孔示意图` / `建模示意图` / `交互式3D模型`

### 命中判定（满足任意两条即通过）

| 证据 | 方法 |
|---|---|
| E1 响应时间 | Network 中第二次请求耗时 < 第一次的 30% |
| E2 输出文件 mtime | `outputs/{sid}/` 对应图片/json 的 mtime 未变化 |
| E3 缓存文件 | `outputs/_cache/{sid}/{cache_type}/` 存在对应 `{input_hash}_{params_hash}.json` |

三条全不满足 = 未命中 = 记入 `test_log.md`（严重）。界面出现"重新计算中"也算未命中。

### 反向验证（必做）

改一个参数（如 smooth 0.1 → 0.2）→ 保存 → 再点"建模示意图"：
- 期望：缓存失效，重新生成，输出文件 mtime 变化
- 仍返回旧结果 → 记入 `test_log.md`

## TC-05 展示一致性

对所有产生图片/结果的功能区（钻孔示意图、建模示意图、AI建模、AI多视角、AI纹理升级、交互式3D模型、各分析结果页）逐项检查：

| 检查项 | 期望 |
|---|---|
| 文字说明 | 每张图有标题/说明 |
| 主图 | 居中、不变形、不溢出容器 |
| 放大按钮 | 位置固定（如右上角），图标一致，行为一致 |
| 下载按钮 | 位置固定，命名规则一致（如 `{功能}_{视角}.png`） |
| 卡片风格 | 圆角、边框、间距、字体与 `.uniform-card` 一致 |
| 空态 | 未生成时占位文案统一 |

任一功能区缺项或风格不一致 → 记入 `test_log.md`，注明功能名 + 缺哪项。
