## 一、需求概述

### 1.1 核心目标

把现有的 RBF 建模抽象为"可切换的插值方法"，让用户可以在参数面板中选择 **RBF** 或 **克里金** 作为建模算法。两种方法的输出结构完全一致（顶底面 + 体层），下游流程（深度图、交互模型、AI 纹理升级）无需修改。

同时，新增一个"克里金参数分析"按钮，与现有的"RBF 参数分析"并列。

### 1.2 关键决策

| 项 | 决策 |
|:---|:---|
| 插值方法选择 | 参数面板中新增下拉菜单（RBF / Kriging） |
| 克里金维度 | 2D 克里金（XY 平面对 Z 插值），与 RBF 一致 |
| 输入控制点 | 每个岩性层的顶面/底面控制点（与 RBF 一致） |
| 输出结构 | 顶底面 + 体层（与 RBF 完全一致） |
| 变差函数 | 默认 spherical，前端可选 |
| 参数分析 | 新增"克里金参数分析"按钮，与 RBF 参数分析并列 |
| 参数分析内容 | 遍历核函数（变差函数）+ 参数，用 LOOCV 找最优 |
| 缓存 | 与 RBF 共用缓存，但缓存键要加 method 标识 |
| 性能容忍 | 1~3 分钟 |

### 1.3 克里金参数搜索范围

**变差函数模型**：`['spherical', 'exponential', 'gaussian', 'linear']`

**关键参数**：克里金的主要参数是变差函数模型 + 各项异性比 + 块金效应，但为了简化，只让用户选择变差函数模型，其他参数由 `pykrige` 自动拟合。

**LOOCV 组合数**：4 个变差函数 × 1（其他参数自动）= **4 个组合**

> 相比 RBF 的 64 个组合，克里金的 LOOCV 会快得多。

### 1.4 RMSE 参考标准（复用 RBF 的）

| RMSE 范围 | 评价 | 建议 |
|:---|:---|:---|
| < 5 m | 优秀 | 直接采用 |
| 5 ~ 15 m | 良好 | 可用于宏观展示 |
| 15 ~ 30 m | 一般 | 需检查数据质量 |
| > 30 m | 差 | 数据可能有问题，或控制点分布太稀疏 |

        Z_bot_c = np.where(mask, Z_bot, Z_top)

        xi_orig, yi_orig = denormalize(xi_n, yi_n)
        bodies[lith] = {
            'X': xi_orig, 'Y': yi_orig,
            'Z_top': Z_top_c, 'Z_bot': Z_bot_c,
            'color': data['color']
        }
        
        # 体层
        layers = []
        for k in range(n_layers + 2):
            t = k / (n_layers + 1)
            Z_layer = Z_top_c * (1 - t) + Z_bot_c * t
            layers.append(Z_layer)
        volume_data[lith] = {
            'X': xi_orig, 'Y': yi_orig,
            'layers': layers,
            'color': data['color']
        }
        
        valid_count = int(np.sum(~np.isnan(Z_top_c)))
        print(f"==> 岩性 {lith} 插值成功，有效网格点: {valid_count}")
    
    # ... 记录 RBF 或克里金分析数据（供数据说明页面用）...
    # 在记录数据时，把 method 也记录进去
    
    return bodies, volume_data

### 3.2 新增函数 `optimize_kriging_params`

```python
def optimize_kriging_params(
    x, y, z,
    variograms=None,
    progress_callback=None
):
    """
    用 LOOCV 评估不同变差函数模型的克里金性能，找最优。
    
    参数:
        x, y, z: 控制点坐标
        variograms: 候选变差函数列表，默认从 config.KRIGING_OPTIMIZE_VARIOGRAMS 读取
        progress_callback: 可选，进度回调函数，签名为 callback(current, total, info)
    
    返回:
        {
            'best': {'variogram': str, 'rmse': float, 'mae': float, 'max_error': float},
            'all_results': [{...}, ...],
            'success': bool,
            'error': str 或 None
        }
    """
    import numpy as np
    from pykrige.ok import OrdinaryKriging
    from config import KRIGING_OPTIMIZE_VARIOGRAMS
    
    if variograms is None:
        variograms = KRIGING_OPTIMIZE_VARIOGRAMS
    
    n = len(x)
    if n < 5:
        return {
            'best': None, 'all_results': [],
            'success': False,
            'error': f'控制点数量不足（{n} < 5），无法可靠评估'
        }
    
    # 归一化
    x_min, x_max = x.min(), x.max()
    y_min, y_max = y.min(), y.max()
    z_min, z_max = z.min(), z.max()
    
    x_span = x_max - x_min if x_max > x_min else 1.0
    y_span = y_max - y_min if y_max > y_min else 1.0
    z_span = z_max - z_min if z_max > z_min else 1.0
    
    x_n = (x - x_min) / x_span
    y_n = (y - y_min) / y_span
    z_n = (z - z_min) / z_span
    
    all_results = []
    best = None
    total = len(variograms)
    
    print(f"==> 开始克里金参数寻优，共 {total} 个变差函数模型，每个模型执行 {n} 次留一验证")
    
    for idx, vgm in enumerate(variograms, 1):
        errors = []
        
        for i in range(n):
            mask = np.ones(n, dtype=bool)
            mask[i] = False
            
            x_train = x_n[mask]
            y_train = y_n[mask]
            z_train = z_n[mask]
            
            try:
                ok = OrdinaryKriging(
                    x_train, y_train, z_train,
                    variogram_model=vgm,
                    nlags=6,
                    enable_plotting=False,
                    verbose=False
                )
                # 单点预测
                z_pred, _ = ok.execute('points', np.array([x_n[i]]), np.array([y_n[i]]))
                err = (z_pred[0] - z_n[i]) * z_span
                errors.append(err)
            except Exception:
                continue
        
        if len(errors) == 0:
            if progress_callback:
                progress_callback(idx, total, f'{vgm} 失败')
            continue
        
        errors = np.array(errors)
        rmse = float(np.sqrt(np.mean(errors ** 2)))
        mae = float(np.mean(np.abs(errors)))
        max_err = float(np.max(np.abs(errors)))
        
        entry = {
            'variogram': vgm,
            'rmse': rmse,
            'mae': mae,
            'max_error': max_err
        }
        all_results.append(entry)
        
        if best is None or rmse < best['rmse']:
            best = entry.copy()
            print(f"  [{idx}/{total}] 新最优: {vgm} RMSE={rmse:.4f}m")
        
        if progress_callback:
            progress_callback(idx, total, f'{vgm} RMSE={rmse:.4f}')
    
    if best is None:
        return {
            'best': None, 'all_results': [],
            'success': False,
            'error': '所有变差函数模型均失败'
        }
    
    print(f"==> 最优变差函数: {best['variogram']} RMSE={best['rmse']:.4f}m")
    
    return {
        'best': best,
        'all_results': all_results,
        'success': True,
        'error': None
    }
```

function renderKrigingAnalysisResults(data) {
    const resultsSection = document.getElementById('resultsSection');
    resultsSection.innerHTML = '';
    resultsSection.classList.add('visible');
    
    const analysisKeys = Object.keys(data.analysis);
    if (analysisKeys.length === 0) {
        resultsSection.innerHTML = '<p>无分析结果</p>';
        return;
    }
    
    const key = analysisKeys[0];
    const result = data.analysis[key];
    
    if (!result.success) {
        resultsSection.innerHTML = `<p style="color:#c62828;">分析失败: ${result.error}</p>`;
        return;
    }
    
    const best = result.best;
    const allResults = result.all_results;
    const standards = data.standards;
    
    let currentStd = standards[standards.length - 1];
    for (const std of standards) {
        if (best.rmse < std.max) { currentStd = std; break; }
    }
    
    let html = '<h2>📈 克里金参数分析结果</h2>';
    
    // 推荐参数卡片
    html += `
        <div class="best-param-card">
            <div class="best-badge">✨ 推荐参数</div>
            <div class="best-param-content">
                <div class="best-param-row">
                    <span class="label">变差函数模型：</span>
                    <span class="value">${best.variogram}</span>
                </div>
                <div class="best-param-row">
                    <span class="label">预期误差 (RMSE)：</span>
                    <span class="value" style="color:${currentStd.color};font-size:18px;">
                        ${best.rmse.toFixed(2)} m
                        <span class="rmse-tag" style="background:${currentStd.color}">
                            ${currentStd.label}
                        </span>
                    </span>
                </div>
                <div class="best-param-row">
                    <span class="label">建议：</span>
                    <span class="value">${currentStd.suggestion}</span>
                </div>
            </div>
            <div class="best-param-actions">
                <button class="btn btn-primary" id="btnApplyBestKrigingParams">
                    ✅ 应用此参数到当前会话
                </button>
                <button class="btn" id="btnCopyBestKrigingParams">
                    📋 复制参数
                </button>
            </div>
        </div>
    `;
    
    // 参数表格
    html += `
        <div class="analysis-block">
            <h3>📋 变差函数明细（按 RMSE 升序）</h3>
            <table class="report-table">
                <thead>
                    <tr>
                        <th>排名</th>
                        <th>变差函数</th>
                        <th>RMSE(m)</th>
                        <th>MAE(m)</th>
                        <th>最大误差(m)</th>
                        <th>评价</th>
                    </tr>
                </thead>
                <tbody>
    `;
    
    const sorted = [...allResults].sort((a, b) => a.rmse - b.rmse);
    sorted.forEach((r, idx) => {
        let std = standards[standards.length - 1];
        for (const s of standards) {
            if (r.rmse < s.max) { std = s; break; }
        }
        html += `
            <tr>
                <td>${idx + 1}</td>
                <td>${r.variogram}</td>
                <td><b>${r.rmse.toFixed(2)}</b></td>
                <td>${r.mae.toFixed(2)}</td>
                <td>${r.max_error.toFixed(2)}</td>
                <td style="color:${std.color}">${std.label}</td>
            </tr>
        `;
    });
    
    html += '</tbody></table></div>';
    
    // 参考标准表
    html += `
        <div class="analysis-block">
            <h3>📖 RMSE 参考标准</h3>
            <table class="report-table standards-table">
                <thead>
                    <tr><th>RMSE 范围</th><th>评价</th><th>建议</th></tr>
                </thead>
                <tbody>
    `;
    
    for (const std of standards) {
        const isCurrent = (std === currentStd);
        const rangeText = std.max >= 99999 ? `> ${standards[standards.length-2].max} m` : `< ${std.max} m`;
        html += `
            <tr class="${isCurrent ? 'current-standard' : ''}"
                style="${isCurrent ? 'background:' + std.color + '22;font-weight:bold;' : ''}">
                <td>${rangeText}</td>
                <td style="color:${std.color}">${std.label}</td>
                <td>${std.suggestion}${isCurrent ? ' ← 当前结果' : ''}</td>
            </tr>
        `;
    }
    
    html += '</tbody></table></div>';
    
    resultsSection.innerHTML = html;
    
    // 绑定按钮
    const btnApply = document.getElementById('btnApplyBestKrigingParams');

## 十、注意事项

1. **性能**：克里金比 RBF 慢 5~10 倍。生成 5 个视角 × 2（标注+无标注）的图可能需要 2~5 分钟。建议加日志提示。

2. **回退机制**：如果克里金插值失败（如控制点太少、矩阵奇异），自动回退到 RBF，保证不 crash。

3. **缓存键**：method 不同 → 缓存不同。修改了 method 后，会自动重新生成。

4. **参数面板**：`INTERPOLATION_METHOD` 和 `KRIGING_VARIOGRAM` 会自动出现在参数面板中（因为它们在 `USER_ADJUSTABLE_PARAMS` 中）。

5. **变差函数选择**：默认 spherical，前端可选。参数分析会推荐最优值。

6. **与"克里金数值分析"的关系**：
   - "克里金数值分析"：输出对比图（RBF vs Kriging + 方差图 + 差异图）
   - "克里金建模"：用克里金作为建模主算法，输出与 RBF 一致的模型
   - 两者独立，不冲突

7. **数据说明页面**：如果用户选择了克里金建模，RBF 数据仍然会记录（因为 RBF 是回退方案）。如果克里金成功，则只记录克里金数据。
